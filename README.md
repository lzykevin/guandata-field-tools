# 观远字段工具

在装有 ScriptCat 的浏览器中打开[集合订阅链接](https://raw.githubusercontent.com/lzykevin/guandata-field-tools/main/guandata-tools.user.sub.js)，确认一次即可安装以下三个脚本。

- 字段快速添加
- 栏目内编辑计算字段
- 重命名字段显示原名

如果浏览器直接显示清单文本，在 ScriptCat 管理面板中选择「链接导入」，粘贴同一个集合订阅链接。

修改脚本后递增该脚本的 `@version`。增删集合中的脚本时，更新 `guandata-tools.user.sub.js` 里的 `@scriptUrl` 和集合版本。
